# Diplom_2

## Дипломный проект. Задание 2: тестирование API для приложения Stellar Burgers. Структура проекта:

### папка methods содержит методы для проверки конкретной функциональности:
создание пользователя

авторизация пользователя

обновление данных пользователя

создание заказа

получение списка заказов конкретного пользователя

папка tests содержит тесты для проверки тестируемой функциональности:
создание пользователя: создать уникального пользователя, создать пользователя с уже используемыми данными, создать пользователя без заполнения обязательного поля
авторизация пользователя: авторизация с валидными данными, авторизация с невалидными данными
обновление данных пользователя: обновление с авторизацией, обновление без авторизации.
создание заказа: создание заказа авторизованным пользователем с указанием ингредиентов, без указания ингредиентов, с указанием неверного хеша ингредиентов; создание заказа неавторизованного пользователя.
получение списка заказов: получение списка заказов авторизованного пользователя, получение списка заказов неавторизованного пользователя.
файл conftest содержит фикстуру создания и удаления пользователя.
файл data содержит тексты ответов от сервера.
файл helpers содержит метод для создания тестовых данных для регистрации пользователя и метод создания данных для обновления пользователя.
файл requirements содержит список необходимых библиотек для работы с данным проектом.
файл urls содержит адрес сервиса и эндпоинты для тестирования.
файл README содержит описание проекта.
папка allure_results содержит отчёт о тестировании.
